SELECTED WORK

Projects.

A collection of research and engineering projects exploring practical approaches to securing containerized systems through runtime analysis, policy generation, and verification.

BeaCon

Environment-Aware Dynamic Policy Generation

BeaCon profiles containers across representative workloads and runtime configurations, collecting dynamic execution evidence using eBPF. It leverages this evidence to generate tunable least-privilege policies, allowing operators to balance attack surface reduction against deployment functionality.

eBPF Runtime Profiling Policy Synthesis
Explore project →

Prompt2Seccomp

Semantics-Aware Seccomp Policy Generation

Prompt2Seccomp enriches sparse container specifications with runtime metadata, application documentation, and deployment context to guide fine-tuned LLM inference. It generates candidate Seccomp policies and validates their deployability through sandboxed execution and runtime feedback.

LLM Inference Deployment Context Policy Validation
Explore project →

VeriKube

Automated Container Network Policy Verification

VeriKube introduces a graph-based representation of container network policies to improve the efficiency of policy verification. It supports the complex semantics of Cilium policies while significantly reducing memory consumption and verification overhead.

Network Policy Graph-Based Verification Cilium
Explore project →

Archon

Requirement-Guided Runtime Evidence Generation

Archon connects high-level deployment requirements to syscall-level evidence by analyzing program structure and identifying requirement-related behaviors. It generates and iteratively refines workload and environment plans to activate these behaviors, then traces execution to classify syscalls as evidence-supported, unconfirmed, or unsupported.

Binary Analysis Behavior Activation Runtime Tracing
